# edst676_final_group_project

Course Project Data - A Subset of National Wellbeing Survey 2024 

Data Source：
The data in NWS24_subset_edst676.csv come from Wave 4 (2024) of the National Wellbeing Survey (NWS). This subset is shared with the permission of the NWS investigators solely for the EDST 676 Introduction to Data Science with R course project.

Data citation:
Monnat, Shannon M., Joshua Grove, Iliya Gutin, Jennifer Karas Montez, Douglas A. Wolf, and Emily Wiemers. 2024. National Wellbeing Survey, United States, 2024. [Accessed October, 2026].
The full dataset is available through ICPSR website (https://www.maxwell.syr.edu/research/lerner-center/health-research/national-wellbeing-survey), subject to its access procedures and Data Use Agreement.

How the subset was derived:
The file contains all 2,528 respondents aged 18–34 from NWS Wave 4 (2024), restricted to the 37 variables listed below. It is an age-based subset, not a random sample of the full dataset.
Variable values and labels are retained as they appear in the public NWS codebook. The file excludes respondent identifiers, survey dates, geographic identifiers, and survey weights.

Included variables:
age, sex, racerec, educ, marstat, sexuality, housing_4, metstat_self, happy, lad_now, lad_fut, child_better, sat1, sat2, sat3, sat4, sat5, hopeful, meaning, res1, res2, res3, res4, res5, res6, lonely_a, lonely_b, lonely_c, relig_attend, volunteer_2, attend_2, social_2, ment_health, pol_party, pol_ideology, vote_2020, intendvote_2024.

Weighting and limitations:
These data are unweighted and are not suitable for population inference. The NWS is a non-probability sample. Analyses in this project are purely illustrative classroom exercises and describe only the included respondents; they must not be interpreted as representative of the U.S. population or U.S. young adults.

The data file will be removed from the repository, including its commit history, by Jan 10, 2027, as confirmed with the NWS investigators. Removal will be confirmed by email to both investigators.
